How it behaves

English to Ancient Tongue remains a best-effort generator based on the active lexicon.

Ancient Tongue parsing now tries normalization, affix splitting, compound recovery, drift rescue, glossing, and idiomatic line reading.

Poetic overrides preserve ritual lines without flattening the underlying morpheme analysis.

Lexicon File

The translator now reads vocabulary from data/lexicon.json.

Rules and notes are loaded from data/rules-notes.md and included in the markdown export.

You can also import any compatible JSON lexicon file with the control above when you want to swap datasets without editing the code.

Use { "confirmed": [...], "inferred": [...] } or a plain array for confirmed entries only.

If you open the page directly from disk and the browser blocks JSON loading, run start-translator.bat to serve it locally without cross-origin issues.
